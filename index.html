Interactive Instance Goal Navigation

SAIN: Structure-Aware Interactive Navigation with Active Dialogue Grounding

Abstract

Most existing vision-language navigation tasks assume that instructions are complete and unambiguous. In realistic robot deployment, however, a user may describe an intended target with incomplete, ambiguous, or spatially underspecified language. Interactive Instance Goal Navigation captures this setting by requiring an embodied agent to identify the intended object instance while resolving uncertainty through active dialogue.

SAIN is a zero-shot framework that converts dialogue feedback into persistent navigation state. Rather than treating answers as one-step textual hints, SAIN organizes them as target evidence, route-level memory, object-candidate labels, and structured spatial context. These states support frontier selection, candidate re-observation, and final target approach under incomplete instructions.

Real-World Challenge

Users rarely provide perfectly grounded navigation commands. Robots must handle missing attributes, ambiguous instances, and changing evidence gathered during exploration.

Existing Gap

Prior navigation systems often consume dialogue as transient language, which limits their ability to preserve spatial, object, and route-level evidence across long-horizon decisions.

Why SAIN

SAIN makes dialogue actionable by storing grounded evidence in structured memories that can be queried throughout exploration, re-observation, and target confirmation.
